## 🧭 About Me

I'm a software developer working primarily with **Java**, **Spring Boot**, and **REST APIs**, building enterprise and backend applications end to end.

What interests me most is understanding how systems work internally and turning that understanding into practical software — whether that's an agentless Linux administration platform or a backend framework written from scratch. My work leans toward networking, deployment workflows, developer experience, and scalable backend architecture rather than only business CRUD applications.

Alongside backend development, I care a lot about **automation and DevOps** — CI/CD pipelines, reproducible builds, and removing the manual steps between writing code and shipping it.
